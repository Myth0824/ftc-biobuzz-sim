The turret (team 32294)

Your robot always has a full 360° turret. It starts aimed straight forward. Use ← → arrows (keyboard) or D-pad (controller) to rotate it — right arrow turns clockwise, left turns counterclockwise, at 180°/s. The dotted arc shows where the next shot will land. The turret holds its angle when you release the keys.

Intake

Hold ↓ (keyboard) or LT (controller) to run the intake. Release to stop. The AI robots intake automatically. Picking up opponent NECTAR (blue balls) is allowed but triggers a G408 minor foul (+5 pts to the opponent).

Scoreboard

H = human-driven (team 32294). B = AI robot (bot). The gear icon ⚙ opens that robot's config. During a match the gear icons are hidden — pause first to access them.

Status bar

The bar at the bottom of the screen shows the controller's name and whether it is connected, and which robot the keyboard drives. A blue dot means keys are held right now. It tucks itself above the AUTO editor's bar while you edit a plan.

Timeline and review

The scrubber bar shows the full match. Gray ticks = MATCH start, TELEOP start, FLOWERS open (1:00), endgame (0:20), and MATCH end. Colored dots = notes. Drag the thumb back during a live match to review — the match waits. Press V or click the Review button to enter full review mode with free-look camera. Press Go Live or R to return.

AUTO path editor

Your robot runs an AI plan during the 30 s AUTO. To edit it: open Game Setup → Edit AUTO paths, or click the gear ⚙ on 32294, choose a plan, and click Edit AUTO paths. The ? button in the editor bar opens this help without leaving the editor.
Orange dotsEach dot is a pose (position + heading). Drag to move it. Arrow on dotThe robot's heading at that position. Drag the tip to rotate. Click a dotOpens Step settings for that drive step: the intake, the turret, and a shoot. Step settingsTick Intake to run it during the drive, with a filter (POLLEN, own NECTAR, or all). Tick Turret to aim it to an angle while driving. Tick Shoot to fire a number of balls right after the step, with a timeout. Adding one to a bare drive step wraps the step in a parallel, and removing them unwraps it again. Steps panelThe list at the right while you edit: click a step to select it, ↑ and ↓ to reorder it, and ✕ to remove it. A shoot that a step added travels with it. Reference pointsNamed positions that steps can follow. Right-click one for Go to reference point, which adds a drive step to it. Add one with Add reference point here, and delete it from the same menu. Create newMakes a new plan: a copy of any existing one, or blank (Start from scratch) for the robot's start position. Edit buttonUnlocks dragging for your plan (system plans are read-only) Undo / RedoCmd+Z / Shift+Cmd+Z Reset this stepPuts a step back to its original position Delete planRemoves your custom plan SnapSnaps drags to a 1-inch grid and turns to 5°. Hold Alt, or Option on a Mac, to do the opposite.

The editor covers most plans. For full control — waypoints, waits, conditions, and the camera's sightings — see the JSON reference below.

AUTO path JSON reference

A path is a JSON file with four sections: defs (named positions), root (the steps), and a few header fields. All positions use red-alliance coordinates: x = red wall (−) to blue wall (+), y = audience (−) to rear (+), headingDeg = degrees CCW from +x axis.
pose(x, y, deg)Define a field position, e.g. pose(−0.5, 1.2, 90) offset(p, dx, dy)Move a named pose by dx, dy meters field.hiveXX of the HIVE pivot (−0.32 m) field.halfHalf the field (1.79 m) field.flowerFar / NearFlower X and Y distances from center bots.me.dimensions.lengthRobot length — use for wall offset math clock.remainingSeconds left — use in waitUntil conditions

Actions (ref):

drive.driveToDrive to a pose. Params: pose, timeoutSec drive.followPathFollow waypoints in order. Params: waypoints, timeoutSec drive.pushPush straight. Params: power (−1 to 1), timeoutSec shooter.shootFire balls. Params: count, timeoutSec, cell (optional) intake.runRun intake while parallel steps run. Params: filter intake.setTurn intake on/off. Params: on (true/false), filter intake.filterRun intake with filter. Params: filter (all/pollen/own_nectar/none) turret.angleAim turret to degrees. Params: degrees, timeoutSec. 0=forward, 90=left, −90=right, 180=behind turret.holdHold turret at current angle. No params. waitWait fixed time. Params: timeoutSec waitUntilWait for condition. Params: condition (expression), timeoutSec vision.waitTipWait for HIVE to tip. Params: cell (rear/audience), timeoutSec

Structure keywords: sequence runs children in order. parallel policy:any runs all children at once and stops when any one finishes — use this to run the intake alongside a drive step.
